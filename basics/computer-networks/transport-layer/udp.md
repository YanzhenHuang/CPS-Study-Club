## UDP: User Datagram Protocol

UDP 是一种无连接的协议：只需定义源端口号和目标端口号即可，不需要建立连接。

[RFC768](https://www.rfc-editor.org/rfc/rfc768.html) 定义的 UDP 报文结构如下：

```
 0      7 8     15 16    23 24    31
+--------+--------+--------+--------+
|     Source      |   Destination   |
|      Port       |      Port       |
+--------+--------+--------+--------+
|                 |                 |
|     Length      |    Checksum     |
+--------+--------+--------+--------+
|                                   | 
|          data octets ...          |
.                                   .
.                                   .
+-----------------------------------+
```

前四个字节（第一行）定义了源端和目标端端口号；第五、六个字节分别定义了保温长度和纠错码；在此之后就是数据 (payload)。注：length 字段所定义的长度包含头部的长度。

## UDP 传输

**发送方**

1. 传输层收到应用层的数据；
2. 传输层确定头部各个字段的值，并将数据封装成 UDP 报文；
3. 传输层将 UDP 报文下方给网络层。

**接收方**

1. 传输层收到网络层发来的 UDP 包；
2. 传输层通过纠错码检查数据完整性；
3. 传输层将数据从 UDP 报文中取出，并传递给应用层对应端口。
